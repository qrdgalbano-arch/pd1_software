These references are not safety limits, redness triggers, or exercise targets. SLR requires a PT-set knee-extended expected AROM, not the general 120° hip-flexion reference. Ankle measurements require knee position documentation. Patient-specific reference overrides are allowed.

PT_SET parameters

Moving-joint ranges, endpoints and tolerances; supporting-joint targets where unspecified and all tolerances; redness scales; repetition thresholds, timing and hold requirements; WNL tolerances; knee-extended SLR expected AROM; patient reference overrides; tracking visibility and filter parameters.

Supplied PT_SET values remain null until a PT enters and approves them.

Visual feedback

Joint-position deviation: color intensity indicates departure from your prescribed exercise limits.

Redness is not pain, injury, inflammation, measured joint stress, or a diagnosis. Shared proportional-redness integration is pending.

Validation

The installed validation utility calculates descriptive comparisons. Passing software tests does not establish clinical accuracy. Real matched camera/goniometer readings and PT review are required.
